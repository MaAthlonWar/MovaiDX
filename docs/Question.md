# 硬件连接与常见问题解答

本章节涵盖了 MovaiDX 的硬件安装细节、接口定义及物理调整方法。

## 1. 组装 MovaiDX
* **安装立式支架**：首先使用随箱附赠的内六角扳手拆掉背面白色饰板的四颗螺丝并取下，打开随箱附赠的拓展包、取出背部支架，安装在刚刚拆下的饰板处。背部支架支持正装与反装。推荐使用**反装**方式以获得更强的支撑稳定性。安装时请务必拧紧全部四颗固定螺丝。
* **使 MovaiDX 变得更稳定**：你可以在背部支架横梁处放置多瓶矿泉水、书本等重物来增强支架稳定性。

## 2. 平板电脑安装与固定
* **安装前的准备**：由于平板需要绝对的居中安装，外壳会使平板产生左右偏移导致画面对不上显示区域，所以首先请确保将平板电脑的外壳摘下。
* **位置调整**：X 轴支架背面设有四颗固定螺丝，首先请拧松它（不要完全拧掉）使支架本体可以上下移动，首先请调节到确保平板能被放入。放入平板后，调整你正在使用的软件的比例和位移（如果有），并将 X 轴支架上下移动到调整至合适的位置，再重新拧紧以确保固定稳固。
    * *个人建议*：在保留游玩画面的基础上尽可能向上移动，这样可能露出更多的副屏，提高美观程度。
* **高度补偿**：在确定好 X 轴支架的位置后，你可以使用随箱附赠的 **黑色 EVA 泡棉胶带** 用于调整平板高度。由于外壳预留空间为 10mm，若平板较薄，请将胶带贴在框体上。
    * *建议贴法*：以轮盘圆心为参考，每隔 120 度粘贴一段，形成三角形支撑，以获得最佳稳定性。

## 3. 背部接口定义
* 首先请先把随箱附赠的弯头 Type-C 线接入平板，弯头在平板侧，出线朝后，连接到主控板。主控板背面共有 **三个 USB-C 接口**：
* **顶部横置接口**：使用配套数据线连接至平板电脑。
    * *注意*：由于功能较为复杂，该接口线缆区分正反，若连接后无反应或无法充电，请尝试翻转接口重新插入。连接正常的标志是：主控板先亮起白色灯光；等一秒后再亮起粉色灯光、同时前面板的 RGB 被点亮。
* **闪电图标接口**：用于外部电源接入（充电）。
    * 我们的设备支持 PD 协议充电。由于大多数国产设备对充电协议进行了私有化修改，可能存在兼容性差异（如充电断续、无法充电等）。目前测试 Apple 设备具有最佳兼容性。
* **USB 图标接口**：用于连接随附的 USB-C 音频转接器（小尾巴），你可以通过连接 **3.5mm耳机** 游玩，你也可以连接任何 USB 协议的设备，包括网卡、硬盘、U盘、甚至是鼠标键盘等。
    * 我们的 USB 接口为 2.0 速率，在使用大容量硬盘时速度可能会受到限制。

## 4. 背部按键和 MovaiDX 功能
* **背部功能键**：从边缘向中心依次为 **[大键盘 3]**、**[大键盘 9]**、**[FN]**。

### FN 组合键功能表
| 组合键 | 功能描述 | 组合键 | 功能描述 |
| :--- | :--- | :--- | :--- |
| **FN + 1** | 切换 RGB 模式 | **FN + 5** | 降低亮度 |
| **FN + 2** | 切换 RGB 颜色 | **FN + 6** | 降低音量 |
| **FN + 3** | 关闭 RGB 灯光 | **FN + 7** | 增加音量 |
| **FN + 4** | 暂停 (Pause) | **FN + 8** | 增加亮度 |


# 移动端软件配置指南

MovaiDX 支持多种移动端模拟器，不同平台的配置要求如下：

## 1. Android 设备
目前有三款主流软件可供选择：
* **KanadeDX**：仅限 1.50 及更早版本（新版本已移除键盘输入支持）。
* **AstroDX**：推荐使用 GitHub RC 2.0 及以上版本。
* **MajDataPlay**：推荐使用 GitHub Nightly 或 Google Play 版本。

## 2. iOS 设备
* **MajDataPlay**：目前已支持。可通过 TestFlight 版或 GitHub Nightly 的 IPA 文件安装。
* **AstroDX**：iOS 版目前存在系统级 API 调用差异（GCKeyboard），存在抬起延迟，表现为长按判定失效或连打中断，相关开发者正在修复中，预计 4 月份更新支持。
* **KanadeDX**：由于开发者未提供针对性支持（GCKeyboard），即使 1.50 及更早版本也无法使用键盘输入。

## 3. 你可能需要了解的配置说明

### MajDataPlay
1. **启用键盘**：需进入 `内置存储/Documents/MajdataPlay/settings.json`。
2. 将 `"EnableKeyboardInput"` 的值修改为 `true`。
    * *提示*：若系统自带文件管理器无法修改 JSON，请下载第三方编辑器。
3. **关键操作**：必须在**启动游戏前**先接入 MovaiDX 手台。
4. **画面调整**：在 `设置 -> 显示设置` 中可调整画面比例、偏移与缩放。如需更精细的调节，可在 `settings.json` 中直接修改数值。

### AstroDX
* **即插即用**：键盘模式为原生支持，无需额外开启。
* **画面调整**：在 `设置 -> 游戏` 中调整“游戏区域大小”和“游戏区域垂直位移”。若选项缺失，请检查并更新至最新版本。
